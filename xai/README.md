# Sugra API Skills for Grok

Sugra API Skills plugin, skills only. Grok package: `.grok-plugin/plugin.json`, `skills/`.

```
grok plugin install Sugra-Systems/sugra-api-plugins#xai
```

The Sugra API MCP server is a separate product: https://docs.sugra.ai/doc-2263382. The skills are copied from [sugra-api-skills](https://github.com/Sugra-Systems/sugra-api-skills) by `scripts/sync.py`; edit them there.

Documentation: https://docs.sugra.ai
